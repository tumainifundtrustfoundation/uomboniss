# Uomboni Secondary School (NECTA S0486)
Tovuti Rasmi na Mfumo Jumuishi wa Taarifa za Shule ya Sekondari Uomboni, Marangu Magharibi, Moshi Vijijini, Kilimanjaro.

## Sifa Kuu za Mfumo (Key Features)
- **Mfumo wa Matokeo ya Mitihani**: Utafutaji wa matokeo ya wanafunzi (NECTA & Ndani ya Shule), ripoti za maendeleo, na kadi za alama zenye QR Code.
- **Portals**:
  - Portal ya Wanafunzi (Student Portal)
  - Portal ya Wazazi (Parent Portal)
  - Portal ya Walimu na Watumishi (Teacher & Staff Portal)
  - Portal ya Mkuu wa Taaluma (Academic Master)
  - Portal ya Mhasibu (Bursar Portal)
  - Portal ya Mkuu wa Shule & Utawala (Admin Portal)
- **Taarifa za Udahili & Joining Instructions 2026/2027**: Nyaraka za kujiunga na maelekezo ya shule.
- **Seva na Usalama**: Seva ya Express yenye ukandamizaji (Gzip/Deflate compression), usalama wa viwango vya juu, na ukaguzi (Audit Logs).
- **Msaidizi wa Akili Bandia (AI Assistant)**: Ushauri wa kitaaluma na taarifa za shule kupitia Google Gemini API (`gemini-3.8-flash`).
- **PWA & Offline First**: Uwezo wa kutumia tovuti bila mtandao (Progressive Web App).

## Uendeshaji (Running Locally)
```bash
# Weka vitegemezi
npm install

# Endesha kwa ajili ya usanidi (Development on Port 3000)
npm run dev

# Jenga kwa ajili ya uzalishaji (Production Build)
npm run build

# Anzisha seva ya uzalishaji
npm start
```
